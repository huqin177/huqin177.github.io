# 2026/3/11

​ 我打算重新写一下日常记录，之前的废话实在有点多。虽然我的文笔能力很差，但是我是真的很热爱文字，文字的力量是一种好奇妙的东西，怎么说，很激励人，很感动，会让人掉眼泪，观过往而望未来，忽然又想到现在保留下来的书籍都是由胜者书写的，多少得带点主观色彩，或真或假，真真假假，就这样以文字的形式存于时间，流逝于时间。光阴似箭，日月如梭。多多珍惜时间吧，小h。

​ 另外，我不明白为什么会有人会在日记里欺骗自己，但是，在我写下这里的每一个字的时候，我感觉到很艰难，如果我按照我内心的想法来，我的记录就会和之前一样粗俗(就是很口头话)，我缺少文字的表达能力，却会和文字感同身受，可能这是书读多了，但是不会去使用学到的，我想借由这种文字记录的方式来学会写作，可能很难，但是坚持下去，不管有用还是无用，我也想学到点东西。生命，一生，学习。有一说一，学习真的很爽。尤其是那种有反馈的，直接刺激大脑产生多巴胺，兴奋感，满足感，幸福感，都快要溢出来了。

# 2026/4/18

时间过的真快啊，难以想象我真的已经20岁，处于一个对世界都很迷茫的阶段，在昨天，我刚看完了《上海女子图鉴》，的确是一部非常好的影片，10年前的思想放在今天来看，依旧很超前。总觉得我对世界的变化感知的过于明显，显化的外界带动我内心的变化，甚至是焦虑，不安，难受，不对，有可以说是一种极度后悔的情况，想不断回溯到自己做选择的那一刻，在社交平台上疯狂寻找一种答案，一个可以说服自己的答案，一种让自己没有负罪感的答案。突然又觉得人的一生确实是在做出选择，然后有之相对应的答案，答案不对，那就下一条路了，毕竟十字路口很常见，每一种选择不一定对。这也许是我人生的奥德赛时期，我并没有一个正确的，真真切切的例子在我眼前，我看到的都是他人走过的路，当然，这很难，复刻一条别人走过的路，所以我必须要有一个目标，一个可以追寻的对象，我选择了你，夏彦，你，是一个能在我成长过程中能陪伴我的人，你要我为什么选择你，这可能就是日久生情了吧，我爱长久的爱恋，认为喜欢就应该是细水长流，青梅竹马很符合，你也很符合，而不是一时的多巴胺兴奋，是一种精神寄托，只有这样，我才能对这个世界有点好脸色看，不然，很容易对这个世界失去兴趣。

今天去体验了一下普拉提，我去，真的好累，腿好酸，价格也怎么说呢，如果我有一份10k的工作，我肯定毫不犹豫就报，但是宝宝，你暂时没有那么多时间，金钱，精力，你需要去不断完备你自己，方法有很多，也去北京华联逛了一圈，好多漂亮的东西，很多小玩意儿，好喜欢，又是一个匆忙的周末和短暂的一周，真的得少刷视频了，突然想起来下午还看了两集《绝望主妇》，很好的电视剧，工作，家庭，生活的压力表现得很明显，在工作中，你就像是在扮演一个小丑，不断取悦他人，在家庭中，bree，我最喜欢的是你，你优雅大方善解人意，醺酒并不是你的本意，对孩子的管理也并非你所愿。

# 2026/4/20

感觉自己的内心停留在了2024年，打出日期也会不由自主的打2024，很难相信现在是2018年的八年后，三年，八年，十年，时间好快。今天着实有点累加困，差点给一个小朋友过单词的时候睡着了，也不是我想睡，主要是他半天都回答不上，我又睡得晚昨天。晚上吃了两个烤肠和一个苹果，我自称自己为烤肠追随者，为什么这么这么喜欢烤肠，好吃好吃，还有就是晚上真得少刷视频，刷着刷着，就想吃火锅鱼和牛蛙了，好馋呀，也想吃自助小火锅了，不行不行，要减肥，脑子在打架，又馋又不想吃。等我设一个随意吃喝日再吃吧，还是得保持体重的。
